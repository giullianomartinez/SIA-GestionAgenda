# SIA - Gestión de Agenda

Proyecto desarrollado en **Java** para la asignatura **INF 2236 - Programación Avanzada**.

El sistema permite gestionar una agenda de actividades y reuniones, organizándolas por fecha, horario y tipo. El proyecto aplica conceptos de programación orientada a objetos, herencia, polimorfismo, colecciones, manejo de excepciones y persistencia de datos.

## Funcionalidades

* Gestión de días y actividades.
* Creación, búsqueda, edición y eliminación de actividades.
* Clasificación de actividades en académicas, personales, proyectos y otras.
* Visualización de la agenda y del historial de actividades.
* Búsqueda de horarios disponibles.
* Modo normal con persistencia de datos y modo prueba con datos iniciales.
* Uso mediante consola o interfaz gráfica con Swing.

## Estructura del proyecto

```text
src/
```

El proyecto se desarrolla de forma colaborativa utilizando ramas e issues de GitHub para organizar las distintas funcionalidades y etapas de implementación.
