# SIA - Gestión de Agenda

Proyecto desarrollado en Java para la asignatura **INF 2236 - Programación Avanzada**.

El sistema tiene como objetivo administrar una agenda de actividades y reuniones, permitiendo organizarlas según fecha, horario y tipo.

## Estructura del proyecto

```text
src/
├── Actividad.java
├── DiaAgenda.java
├── SistemaAgenda.java
└── Main.java
```

* **Actividad:** representa una actividad o reunión.
* **DiaAgenda:** almacena las actividades correspondientes a una fecha.
* **SistemaAgenda:** administra los días y actividades de la agenda.
* **Main:** contiene el punto de entrada del programa.


## Tecnologías utilizadas

* Java
* Apache Netbeans
* IntelliJ IDEA
* Github
